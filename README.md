# gaugescope

Gauge color scope values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/gaugescope/

## Install / run

```bash
git clone https://github.com/theworker02/gaugescope.git
cd gaugescope
node src/cli.js
node --test
```
